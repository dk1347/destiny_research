# 🚀 Destiny 무자본 마케팅 & 트래픽 자동화 파이프라인 가이드

본 문서는 사주 엔진(`destiny`)의 초기 브랜드 인지도 확보 및 웹 유입 깔때기(Funnel)를 자본금 0원으로 구축·운영하기 위한 단계별 실행 전략을 정의한다. 플랫폼 정책(어뷰징/저품질)을 준수하며 개발 본업에 지장을 주지 않는 최소 리소스(반자동/배치) 워크플로를 원칙으로 한다.

---

## 📌 파이프라인 개요 및 우선순위

```text
[1단계: 최우선 기본 루틴] (소요시간: 건당 30초)
네이버 블로그 포스팅 ➔ Meta AI 카피 추출 ➔ X / 스레드(Threads) 배포

[2단계: 고관여 타깃 공략] (소요시간: 일 5분)
지식iN 모니터링 ➔ 텔레그램 실시간 알림 ➔ AI 답변 초안 ➔ 1-Click 등록

[3단계: 무작위 트래픽 확장] (소요시간: 주 1회 30분)
블로그 텍스트 추출 ➔ Edge-TTS 음성 ➔ 무료 비디오/자막 합성 ➔ 쇼츠/릴스 예약
1단계 (전략 1순위): 블로그 ➔ SNS(X·스레드) 30초 반자동 배포
목적: 네이버 블로그 검색 유입에 더해 2030 여성/자기이해 관심층을 실시간으로 견인.

비용: 0원 (Grok 구독 및 유료 X API 일절 배제).

리스크 방지: 봇을 통한 API 전송이 아닌 '사람의 1-Click 복붙'으로 계정 정지 원천 차단.

실행 워크플로
블로그 글 발행: 네이버 블로그에 정보성 칼럼(운명과 숙명, MBTI 결합형 등) 발행 후 링크 복사.

Meta AI 프롬프트 투입:

"방금 쓴 [블로그 제목 및 핵심 3줄]을 바탕으로 X와 스레드에 올릴 손가락을 멈추게 하는 140자 공감 카피 2개 뽑아줘."

채널별 규칙 준수 배포:

X (구 트위터): 140자 텍스트 + 본문 끝에 블로그 URL 첨부 ➔ 즉시 게시.

스레드 (Threads): 본문에는 텍스트만 게시, 블로그 URL은 반드시 '첫 번째 댓글(대댓글)'에 남기고 고정(Pin) (본문 링크 시 도달률 저하 방지).

2단계 (전략 2순위): 네이버 지식iN 고관여 타깃 알림 & 반자동 답변
목적: 지금 당장 사주·오행·궁합·운세를 보고 싶어 하는 '구매 의사 100%' 유저 직접 유입.

비용: 0원 (Python 스크립트 + Telegram Bot API 무료).

리스크 방지: 자동 댓글 등록 매크로는 100% 영구 정지 대상이므로, '알림 + 초안 작성'만 자동화하고 최종 검토 및 등록은 사람이 수동 진행.

아키텍처 및 워크플로

[지식iN RSS/검색 모니터링 (Python Cron / 1시간 주기)]
  ↓ ("사주 오행", "신년운세", "대운" 등 타깃 키워드 매칭)
[LLM 초안 생성기 (무료 Web/API)]
  ↓ (전문적이고 친절한 기본 풀이 작성)
[내 스마트폰 텔레그램 봇 알림 전송]
  ↓
[스마트폰에서 내용 확인 후 네이버 지식iN 앱에 10초 만에 답변 붙여넣기]
  - 출처 및 네임카드에 '운명과 숙명 블로그' 또는 프로필 링크 노출
3단계 (전략 3순위): Edge-TTS 기반 무얼굴 숏폼(Shorts/Reels) 자동 렌더링
목적: 알고리즘 무작위 트래픽(Cold Traffic)을 흡수하여 구독자/방문자 기반 확장.

비용: 0원 (오픈소스 툴 조합).

방식: 주말 1회 배치(Batch) 작업으로 주간 분량(5~7편) 일괄 생성 후 예약 발행.

툴체인 파이프라인
스크립트 추출: 블로그 글 중 호기심 유발 구간을 30초 분량(약 120자)으로 정돈.

무료 음성 합성: 마이크로소프트의 오픈소스 라이브러리인 edge-tts(파이썬 패키지)를 활용해 자연스러운 한국어 나레이션 MP3 자동 추출.

영상 & 자막 렌더링:

Pexels/Pixabay 무료 감성 영상 소스 배치.

파이썬 moviepy 스크립트 또는 CapCut PC 템플릿에 음성+자막(SRT)+배경을 얹어 9:16 세로 영상 MP4 일괄 렌더링.

배포: 유튜브 스튜디오 및 인스타그램에 고정 댓글(블로그/웹 링크) 달고 매일 1편씩 예약 발행.

📋 규칙 및 준수 사항 (Fail-Safe)
플랫폼 규정 우선:

각 플랫폼이 금지하는 대량 기계식 스팸 행위를 하지 않는다.

지식iN 댓글, 네이버 블로그 포스팅 등 핵심 자산 영역은 반드시 사람의 육안 검수를 거친다.

도메인 연결 대비:

향후 destiny 엔진이 연동된 독립 도메인 배포 시, 모든 SNS 프로필 링크 및 블로그 CTA를 해당 단일 공식 링크로 일원화한다.
